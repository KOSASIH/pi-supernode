    ## 🛠️ Quick Start & Deployment
    
    ### 1. Clone & Initialize
    \`\`\`bash
    git clone https://github.com/KOSASIH/pi-supernode.git
    cd pi-supernode
    git checkout main
    \`\`\`
    
    ### 2. Configure Environment
    \`\`\`bash
    cp .env.pantheon .env
    \`\`\`
    
    ### 3. Launch Pantheon OS Cluster
    \`\`\`bash
    docker compose -f docker/docker-compose.v200.yml up -d --build
    \`\`\`
